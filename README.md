# Proyecto CumpleFer

Pequeña página web de celebración escrita en HTML y CSS. Incluye una pantalla de bloqueo con animación y una sección de celebración para una felicitación especial.

## Estructura

- `index.html` - Página principal.
- `img/` - Carpeta para imágenes usadas en la página.

## Uso

1. Abre `index.html` en un navegador.
2. Disfruta de la animación y el contenido de la felicitación.

## Desarrollo

Puedes editar directamente `index.html` para ajustar estilos, texto o animaciones.
